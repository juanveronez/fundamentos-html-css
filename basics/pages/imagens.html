Uso de imagens

A primeira coisa importante de percebermos quando falamos sobre imagens no conceito da web é que existem os direitos autorais!

Isso significa que nem toda imagem pode ser pega e utilizada livremente, algumas imagens precisam ser pagas para uso comercial (licença comercial) outras precisam que seus créditos sejam disponibilizados no seu uso (licença criativa)

Se quisermos usar o Google Images para procurar imagens com licença criativa (mais recomendada) precisamos ir em tools > creative commons licenses

Alguns dos sites mais indicados para imagens(além do Google Images):

  • Unsplash
  • Pexels

Formato de imagens

Quando falamos sobre tipos de imagens as mais comuns são:

  • jpeg: Formato mais comum para imagens, oferece uma boa resolução e compressão
  • png: Oferece opções de transparência, ideal para logos ou imagens sobrepostas
  • svg: Formato vetorial usado para ícones ou formas geométricas, muito otimizado e garante resolução indepente do tamanho
  • WebP: Formato mais moderno, lida com imagens como se fosse um jpeg/png, porém lida melhor com compressão e tamanho de arquivos, sendo mais otimizado

Compressão de imagens

Quando lidamos com imagens muitas vezes o ideal é não utilizar a imagem na resolução padrão, mas alterar a imagem com base no dispositivo que vamos exibir. Como padrão podemos usar esses valores normalmente:

  • Desktop: 1900px (largura)
  • Tablet: 720px (largura)
  • Smartphone: 480px (largura)

Para isso podemos usar ferramentas de redimencionamento e mudança de qualidade como o GIMP, usado para editar imagens, inclusive isso.

Por outro lado, muitas vezes apenas isso não é suficiente, nesses momentos o que pode ser usado é algo como o TynePNG.
