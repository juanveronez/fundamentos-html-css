Links

Quando falamos sobre links temos alguns tipos mais comuns, como ancoras (que levam para outra parte da mesma página), links relativos (levam pra outra página, mas ainda do seu domínio) ou links exteros.

Importante falar que quando estamos lidando com links externos é importante utilizar o target do tipo blank, para fazer com que o usuário retorne mais facilmente para nossa página, garantindo uma melhor retenção.

Além disso, quando falamos sobre target blank é importante lembrar que é importante definir a relation entre o seu site e o link que está colocando ali, para esses casos a rel mais comum é "external"

Alura

Por outro lado, quando falamos sobre uso do blank para páginas do nosso site o rel não é necessário (por ser uma página interna)
